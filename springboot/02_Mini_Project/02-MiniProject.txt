========================
02 - Mini Project Requirement 
========================

Develop Front Office Team Portal for Managing Student Enquiries


============
Functionalities
============

1) Home Page with carousel

2) Sign Up

3) Unlock Account

4) Login (Only unlocked account users can login)

5) Dashboard (Logged in user performance report)

6) Add Enquiry

7) View Enquiries (with Dynamic Filters)

8) Edit and Update Enquiry Status

9) Filter Enquiries

10) Logout

Note - 1 : When user logged in, only that logged in user performance report should display in dashboard and only that user added enquiries should display in view enquiries screen.



Front Office Team : registration/unlock/login/dashboard/forgot-password
Student Enquiries : Add Enquiry / View Enquiries / Edit & Update

==============
Technology Stack
==============

Database : MySQL

Backend : Java + Spring Boot + Data JPA + Web MVC

Frontent : HTML + CSS + JQuery + Bootstrap + Ajax + Thymeleaf


============
Execution Flow
============

1) User will open website home page

			-> Logo Display with Nav bar
			-> Carousel (banners sliding)
			-> Carousel Image Display
			-> Login Button

2) User Registration

			-> Unique Email Validation
			-> Temporary Password should be generated by application
			-> Send Registration Email with Temporary Password and Unlock Link

3) Unlock Account

			-> Temporary Password Validation
			-> Set New Password
			-> Unlock Account

Note: User should unlock account only one time. If user try to unlock account second time then application should display message as "Your account is already unlocked".

4) Login Functionality

			-> Unlocked account users only can login
			-> Invalid Credentials Check (error : Invalid Credentials)
			-> Account Status Check (error : Your account locked)

5) Forgot Password

			-> Invalid Email : No Account Found With Given Email
			-> Valid Email : Get Password from Database and Send User Password to User Email

6) Dashboard

			-> Display logged in user performance report

7) Add Enquiry

			-> Add new Enquiry with status as 'New'

8) View Enquiries

			-> Display enquiries which are added by logged in user
			-> Edit enquiry to update enquiry status
			-> Filter enquiries based on given criteria (Asynchronously)

9) Logout

			-> When user click on logout display home page

--------
AJAX
--------

2 Types of requests

1) Synchronous Request (whole web page will be reloaded)
2) Asynchronous Request (DOM will be updated without reloading page)

Note: To send Asynchronous request to server we can use AJAX.

-> AJAX stands for Asynchronous JavaScript and XML.

1) We can reload only data without loading whole page.
2) We can send/read data to/from server in asynchronous mode.
3) Seamless experience for end user.


1) Add jquery dependency in pom.xml

<!-- https://mvnrepository.com/artifact/org.webjars/jquery -->
<dependency>
    <groupId>org.webjars</groupId>
    <artifactId>jquery</artifactId>
    <version>3.7.1</version>
</dependency>

2) Include jquery.min.js file in our html page in <head/> tag.

<script src="/webjars/jquery/3.7.1/jquery.min.js"></script>

3) Write ajax logic to send asynchronous request to server.

$(document).ready(function() {
	$(".form-select").on("change", function(e) {
		$.ajax({
			type: "GET",
			url: "filtered-enquiries",
			data: {
				course: $("#course").val(),
				status: $("#status").val(),
				mode: $("#mode").val()
			},
			success: function(result){
				$("#enquiryTable").remove();
				$("#filteredEnquiryTable").html(result);
			}
		})
	});
});
